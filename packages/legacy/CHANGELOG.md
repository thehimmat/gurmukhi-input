# @atthebunga/gurmukhi-legacy

## 0.1.0

### Minor Changes

- First release: a TypeScript port of gurmukhi-transliterate's legacy-font converter.
  - `convert`, `toUnicode` and `encodingForFont` for the AnmolLipi/GurbaniAkhar, Asees, Joy, AnandpurSahib, Satluj and SONY layouts.
  - New: `fromUnicode`, for Unicode → AnmolLipi.
